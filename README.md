## 本轮敌人动作

剑兵、弓手、蝙蝠和守誓者改用可转向的像素关节模型：脚步按移动距离推进，手臂、躯干、武器、翅膀和披风分别运动。剑兵的横斩/回斩/直刺、弓手的搭箭拉弦、蝙蝠的扑翼俯冲，以及 Boss 的举盾冲锋/低扫/重刺/震地各有独立姿势。

敌人的出招阶段由战斗逻辑计时，伤害和箭矢在动作接触点触发，完成随后的收势才进入连招间隙或恢复。攻击预警保留到接触前，剑光跟随实际武器。剑兵攻击距离按真实剑锋校正为横斩/回斩 2.0、直刺 2.1；伤害数值、玩法按键和地图沿用上一版。

## 打开与操作

直接打开 `草帽与猫-暮丘遗迹-v15.html`，点击“踏入荒庭”。脚本、模型、贴图、字体、8-bit 音乐和许可证均已内嵌，不需要联网、安装或服务器。

| 动作 | 按键 |
|---|---|
| 移动 / 自由转镜头 | WASD / 鼠标 |
| 疾跑 / 跳跃 | 按住 Shift / 空格 |
| 闪避 / 猫扑 | Q / E |
| 切换剑盾与弓箭 | C |
| 剑盾斩击 / 格挡 | 左键 / 按住右键 |
| 精准格挡后反击 | 提示窗口内左键 |
| 弓箭蓄力、松开发射 | 按住左键或右键 |
| 喝药 / 交互 / 暂停 | R / F / Esc |

鼠标捕获不可用时，移动鼠标转向，停在画面边缘可继续转向。C 切武器后须重新按下攻击/格挡键。红色十字提示的 Boss 招式不可格挡。

## 本版内容

- 南侧低谷、上坡古道、东侧遗迹台地和北侧高地礼拜堂。地形网格与角色、敌人、箭矢、镜头共享高度查询。
- 实际使用 Kenney Castle Kit / Nature Kit 模型，统一石材与植被配色，低分辨率像素渲染。
- 一个 1024 × 1024 方向光阴影贴图，降低环境光；人物与猫接受同一套灯光。
- 斩击从实际上一帧姿势过渡，连击保留上一刀收势；脚部适应坡面。保留伤害窗口、体力与格挡规则。
- 镜头避障加入肩侧选择、地形避让和遮挡恢复；处理鼠标捕获切换的输入状态。

营火恢复生命和药瓶、普通敌人重生；东侧台地与西侧近路有遗物。死亡掉落余烬，返回可拾取。探索进度仅保存在当前页面内。

## 来源与构建

Kenney：[Castle Kit](https://kenney.nl/assets/castle-kit)、[Nature Kit](https://kenney.nl/assets/nature-kit)，CC0。`assets/kenney/manifest.json` 保存下载来源与哈希；`assets/kenney/selected/` 保留选中模型原件、色表和许可证。转换后的几何在 `src/asset-library.js`。

安装 Node 后运行 `node build.cjs dist` 可重新生成单 HTML。构建只内嵌资源并编译检查语法，不执行游戏。`tools/convert-kenney.cjs` 用于转换素材，不影响直接构建。

## 验证边界

遵照用户“先不要测试”的要求，未启动游戏、浏览器、服务器、渲染器或测试程序。仅进行静态源码审查、语法编译与素材/压缩包完整性检查；画面效果、浏览器行为、帧率和实际战斗手感尚未实测。
